## 3. 不同消息对应的实际控制约束

三个径向运动邻机和一架受控平面双积分器。在t=1计算未来0.5秒的常加速度。
免费位置/速度观测每0.2秒获得一次，误差各为0.04。额外消息统一在t=.8采样、
t=1到达、误差0.001；三种方案都固定向三个邻机各收一个同类标量，共3包。
控制QP最小化相对标称u=(1,0.4)的修正量平方的一半。

| 固定收到的额外消息 | 包数 | 认证控制u_x（u_y均0.4） | 控制修正代价 |
|---|---:|---:|---:|
| 无 | 0 | 0.613462 | 0.074706 |
| 位置 | 3 | 0.690545 | 0.047881 |
| 速度 | 3 | 0.704536 | 0.043650 |
| 实际加速度 | 3 | 0.935362 | 0.002089 |

每个QP都有精确KKT证书，且使用连续时间插值缓冲，保证声明模型内这0.5秒中
ego对每个邻机的间距至少0.6。已显式检查当前端点，不能仅凭未来两个采样点
安全就外推段间安全。没有宣称该QP对原非凸避碰问题全局最优或下一步仍可行。

消息类型是预先固定的对照方案。尚未实现“回复前选谁/选哪种量”的决策器，
不把事后看到哪个回复效果好当成可执行的主动策略。加速度优势仅是该短时
布局和数据下的结果，不保证在其他运动、传感精度或同字节编码下仍成立。
